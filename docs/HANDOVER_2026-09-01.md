## 3. How to run it

```bash
mvn clean package -DskipTests          # -DskipTests required: 7 Testcontainers classes fail on dev
export AZURE_CLIENT_ID= AZURE_USER_USERNAME= AZURE_USER_PASSWORD=
java -jar -Dspring.profiles.active=azure,development \
     -Dspring.cloud.azure.keyvault.secret.endpoint=https://bc-dev-vault-dev.vault.azure.net/ \
     -Dserver.port=8081 \
     -Djobrunr.dashboard.enabled=false \
     -Dorg.jobrunr.dashboard.enabled=false \
     -Dorg.jobrunr.database.database-name=betterco-jobs-p1 \
     target/betterco-backend-0.0.1-SNAPSHOT.jar
```

The `AZURE_*` variables are set **empty on purpose** — `DefaultAzureCredential` then walks its chain
to the box's `az` CLI login, which can read the vault. The last three flags are **not optional**;
see §4.

Sandbox proof before ordering anything: `…/document-search/cases/search?jurisdiction=GB&query=LIMITED`
must return 5 fixtures with `CROPWELL BISHOP CREAMERY LIMITED | 00364890` first. Real Companies
House data means you are on production — stop.

## 4. Traps that have already cost time

- **A second backend runs on the dev box at port 8080**, profile `azure,local`, no sandbox config,
  therefore pointing at the **live vendor**. Both instances share the JobRunr queue, so an async
  create enqueued by the sandbox instance can be executed by the production-facing one — and the
  fixture check would not catch it. `-Dorg.jobrunr.database.database-name=betterco-jobs-p1` isolates.
- **The vendor's document path is case-sensitive.** `/v2/Documents/{id}` returns bytes;
  `/v2/documents/{id}` 404s. Fixed on the branch; **still broken on `dev`**.
- **Document type comes from `name` minus its trailing `<date>`, not `category`.** The vendor:
  *"the category field is currently not normalized across jurisdictions and should not be considered
  a canonical document type."*
- **CI verifies nothing before an approving review** — `app-tests.yml` is gated on
  `github.event.review.state == 'approved'`. Verify locally instead; judge by *no new failures*
  against the `dev` baseline, never by a green suite.
- **`graphify-out/`** in `betterco-backend` is an untracked tool cache. Do not commit it.

## 5. Decisions

- **D1 retention — answered.** Kept indefinitely; deleted with the client; reusable across customers
  while fresh (`fetchedAt` < 7 days, per source). Note the cascade **does not exist today** —
  `CustomerService.deleteAllClientInfo` already orphans documents.
- **D6 — open.** Whether kyc.com's licence permits serving a document bought for one customer to
  another. Never asked. Blocks the least-cost thesis, not P2.
- **Documents are stored nowhere.** `downloadUrl` is our proxy; bytes stream from the vendor on each
  request. If the vendor drops a document there is no copy and no record it existed. That is what P2
  fixes, and it is the strongest argument for doing P2 next.
